## Состав репозитория

* `mephi-screenshot.png` — визуальное подтверждение выполнения с уникальным номером студента.
* `history.out` — история выполненных команд.
* `stat.out` — информация о правах доступа к `/home/user1`, `my_cat` и `my_chown`.
* `getcap.out` — вывод установленных привилегий (`capabilities`) для `my_chown`.
* `Getfacl.out` — списки контроля доступа (ACL) домашней директории `/home/user1`.
* `suid_files.out` — перечень файлов в системе с установленным битом `set-UID`.
* `suid_procs.out` — вывод мониторинга процессов с `EUID = root` и реальным обычным пользователем.
* `passwd`, `shadow`, `group`, `sudoers` — копии системных конфигурационных файлов с применёнными настройками.
